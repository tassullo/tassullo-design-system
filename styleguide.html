Come si usa

In Studio Tassullo: i token sono già importati da index.css; nei CSS di pagine e componenti usa solo var(--…), mai valori hardcodati. In una nuova app:

Setup nuova app (4 passi)
/* 1. Installa il pacchetto condiviso:
      npm install github:tassullo/tassullo-design-system */

/* 2. Nel CSS globale, come prime righe: i token e poi i componenti. */
@import '@tassullo/theme/theme.css';
@import '@tassullo/theme/components.css';

/* 3. Reset di base: */
* { box-sizing: border-box; }
body {
  margin: 0;
  font-family: var(--font-family);
  background: var(--color-page-bg);
  color: var(--color-text);
}

/* 4. App usata in campo (guanti, schermo piccolo)? Nell'index.html:
      <body data-density="touch">
   e i bersagli passano a >=48px. Le app desktop dense non lo mettono. */

/* Da qui in poi: nei CSS di pagina SOLO var(--token), mai valori
   hardcodati. Lo verifica la config stylelint del pacchetto:
   extends: '@tassullo/theme/stylelint-config'  */

/* Per ribrandizzare mantenendo l'impianto: cambia solo i token
   --color-accent* (e volendo la sidebar); tutto il resto segue. */
