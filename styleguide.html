Tassullo Design System

Style guide di Studio Tassullo · v1 · luglio 2026

Sidebar antracite, superfici bianche su grigio freddo, un solo accento: l'ocra Tassullo. Tutti i valori vivono in frontend/src/styles/theme.css — copia quel file in una nuova app e importalo per primo: questa pagina documenta i token e le ricette dei componenti costruiti sopra.

Tipografia

Font di sistema (-apple-system, 'Segoe UI', system-ui): l'app è uno strumento di lavoro quotidiano e adotta il font della piattaforma. La gerarchia si costruisce con corpo e peso, non cambiando famiglia. Monospace solo per codici sistema e dati tabellari.

Come si usa

In Studio Tassullo: i token sono già importati da index.css; nei CSS di pagine e componenti usa solo var(--…), mai valori hardcodati. In una nuova app:

Setup nuova app (3 passi)
/* 1. Copia frontend/src/styles/theme.css nella nuova app */

/* 2. Nel CSS globale, come prima riga: */
@import './styles/theme.css';

/* 3. Reset di base: */
* { box-sizing: border-box; }
body {
  margin: 0;
  font-family: var(--font-family);
  background: var(--color-page-bg);
  color: var(--color-text);
}

/* Per ribrandizzare mantenendo l'impianto: cambia solo i token
   --color-accent* (e volendo la sidebar); tutto il resto segue. */
